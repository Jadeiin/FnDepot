# Kavita

漫画和电子书阅读服务。首次打开 `http://NAS-IP:5000/` 后创建管理员并添加授权书库路径。包 ID 为 `kavita-native`，账号、书库数据库、封面和设置保存在 `TRIM_PKGVAR/config`。若旧服务已占用 `5000`，先停止旧服务。 [上游原生安装说明](https://wiki.kavitareader.com/installation/native/)

GitHub Release 标签和文件名保留完整的四段上游版本。包内版本例如由 `v0.9.1.4` 转为 `0.9.1004`。 [上游发布](https://github.com/Kareadita/Kavita/releases) · [图标来源](https://github.com/Kareadita/Kavita/blob/v0.9.1.4/UI/Web/src/assets/icons/android-chrome-256x256.png)
